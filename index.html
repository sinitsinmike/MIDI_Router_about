MIDI Router

Аппаратный MIDI-роутер и процессор на Raspberry Pi Pico. Проект разделяет декодирование MIDI, обработку сообщений и обычную маршрутизацию, а конфигурация управляется из браузера через WebSerial.

Устройство

Что это

MIDI Router принимает MIDI-сообщения с нескольких входов, декодирует их, при необходимости пропускает через специальные processors и отправляет результат на один или несколько MIDI-выходов. Основная идея — сохранить routing простым и предсказуемым, а специальные функции держать отдельно.

6 × 6 Routing MatrixОбычная маршрутизация входов, MIDI channels и выходов.
Keyboard SplitРазделение клавиатуры по ноте с отдельными output/channel для low/high зоны.
Note CloneFan-out Note On/Off на выбранный output и несколько MIDI channels.
MIDI ClockГлобальный Enable MIDI Clock для Real-Time сообщений.
MIDI CCГлобальный Enable MIDI CC для Control Change.
WebSerial UIБраузер настраивает firmware через USB Serial.

Приоритет

1. MIDI Decoder
   ↓
2. Глобальные фильтры
   - MIDI Clock
   - MIDI CC
   ↓
3. Специальные processors
   - Keyboard Split
   - Note Clone
   ↓
4. Обычная Routing Matrix
   ↓
5. MIDI Output
Если Split или Note Clone явно задаёт destination, этот destination имеет приоритет над обычным выбором через Routing Matrix для данного события. Поэтому выключение OUT в Matrix не отключает автоматически явно заданный output Split/Clone.

Функции

Routing MatrixДля каждого input выбираются MIDI channels и OUT-порты. ALL соответствует CH=-1.
Keyboard SplitПравило привязано к Input + MIDI channel. Ноты ниже split — low zone, остальные — high zone.
Note CloneСовпавшее правило заменяет обычную маршрутизацию для события и создаёт Note events на заданном output/channel.
MIDI SettingsEnable Note Clone, Enable MIDI Clock и Enable MIDI CC.

Семантика MIDI CC

Enable MIDI CC сейчас управляет всеми Control Change (0xB0) глобально. Pitch Bend (0xE0) и Aftertouch этим переключателем не управляются.

Направление CC filtering

Предпочтительное следующее расширение — фильтр на уровне Input: Input 1 → CC allowed, Input 2 → CC blocked. Per-output filtering имеет смысл только при реальной задаче использовать разные наборы CC для разных destination.
